번역·판본 안내

한국어로 읽는 고대문헌

그리스어와 라틴어 본문에서 직접 옮긴 한국어 번역을 제공합니다. 유대고대사 18권 18권 전문, 십계명에 관하여 178절 전문, 엥케이리디온 53장 전문, 도덕서한 47 47서간 전문, 호의에 관하여 1권 1권 전문을 수록했습니다. 다른 문헌 5편의 선별 본문을 포함하여 총 779개 대목을 읽을 수 있습니다.

한국어 아래에는 사용한 원문을 실었습니다. 왼쪽 장절에 링크가 있으면 해당 대목의 번역 메모로 이동합니다. 전문 수록 문헌에서는 표현에 마우스를 올리거나 터치하면 대응하는 원문과 한국어가 함께 강조됩니다.

원문과 번역

한국어 본문은 Codex가 원어에서 직접 작성했습니다. 기존 현대어 번역을 중역하지 않았습니다. 원어 전공자의 독립된 검토는 아직 이루어지지 않았습니다. 실제 사용 판본과 번역·검토 기록은 문헌별 자료에 연결되어 있습니다.

사용한 판본과 편집 표기는 각 문헌의 자료에 기록했습니다. 본문 속 보충은 표시를 남겼고, 교감 각주와 현대 편집자의 참조는 본문에서 분리하여 보존했습니다. 단어·구 대응은 현재 번역의 의미를 설명하는 읽기 보조 자료입니다.

신약 본문과 함께 읽기

성경 본문별 연결은 주제와 표현을 비교할 수 있는 자료를 안내합니다. 문헌 의존이나 직접 인용의 주장은 각 관계의 실제 어휘, 문맥과 전승을 따로 조사해야 합니다.
